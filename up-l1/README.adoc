== Independent choices in uP-L1

Transport composition separates these independent choices; each is fixed by setup/declaration rather than switched silently at runtime:

* *Contract family:* Classic `UTransport` (`utransport.adoc`), `up-rust` SEooC (`+req~ssr-*+`, `+aou~seooc-*+`), or opt-in no-ASIL owned-frame SDK (`+req~sdk-owned-frame-*+`) — see xref:../contract-generations.adoc[contract generations]. Classic `UTransport` is a contract family rather than a serialized payload format, and an owned frame is an ownership boundary rather than a payload representation of its own (it can carry either a native or a serialized payload).
* *Payload representation and wire:* Native in-place representation (xref:wires/native.adoc[`wires/native.adoc`]) or serialized encoding (xref:wires/serialized.adoc[`wires/serialized.adoc`], xref:wires/xcdrv2.adoc[`wires/xcdrv2.adoc`]), optionally wrapped with xref:wires/e2e.adoc[end-to-end protection].
* *Frame ownership and delivery model:* Lending versus handoff storage (xref:../basics/resources.adoc#req-ssr-mode-two-types[shared vocabulary], xref:bindings/interface.adoc[binding interface], xref:bindings/storage.adoc[binding storage]) and push versus pull delivery (xref:utransport.adoc#delivery-method[Classic delivery methods], xref:runtime.adoc[transport runtime]), independent of decoded-value ownership (xref:../basics/ownership.adoc[ownership]).
* *Middleware binding versus protocol mapping or service translation:* Middleware protocol mappings and SEooC profiles live in xref:bindings/README.adoc[`bindings/`]; xref:someip.adoc#someip-service-translation[SOME/IP] defines a service translation (not a `UTransport` binding), and xref:cloudevents.adoc[CloudEvents] defines a message/envelope mapping (not a middleware binding).
* *Memory-provider selection:* Selecting a memory source or allocation provider (xref:../basics/resources.adoc#req-sdk-owned-frame-provider-selection[The selected memory provider is the only one used, and selecting it claims nothing]) fixes storage origin and disposal rules without selecting a payload representation, bypassing Class 2 permits/waivers or establishing any timing or stronger resource guarantee.
* *Integrity, resource guarantees and timing claims:* Transport integrity level and copy-route rules (xref:integrity.adoc[`integrity.adoc`]), runtime heap classes, permits, waivers and stronger guarantees (xref:../basics/resources.adoc[`basics/resources.adoc`]), logical deadlines and bounded work (xref:runtime.adoc#req-ssr-bound-wait[Every bounded wait has a logical deadline]) separate from physical timing budgets and supported-configuration timing packages (xref:../safety/elements/up-rust/assumptions-of-use.adoc#aou-seooc-timing-budgets[Timing claims rest on a supported configuration, and the item's budgets are the integrator's]), and claim-scoped assumptions of use (xref:../safety/elements/up-rust/assumptions-of-use.adoc[assumptions of use]).
